# Counter Project

Практичне завдання 2 з теми "Замикання" в JavaScript.

Функція createCounter(initial) створює лічильник із приватним значенням.

Методи лічильника:

- increment() — збільшує значення на 1
- decrement() — зменшує значення на 1
- getValue() — повертає поточне значення
- reset() — скидає значення до початкового
